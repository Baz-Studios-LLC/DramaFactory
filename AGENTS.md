## Architecture
- `src/main.rs`: eframe/egui desktop, embedded branding, native dialogs.
- `src/shot_workspace.rs`: searchable shot list + focused inspector, current-shot take filtering, large references and independent shot-form text. Forms snapshot on exit/context change; recovery UI and expected-state legacy shot-plan saves remain incomplete.
- `src/workflow_ui.rs`, `src/project_context.rs`, `src/episode_ui.rs`, `src/image_inspector.rs`: shared production stages, remembered GUI series/episode context, ordered/searchable episode browser and full-size reference inspection. Existing asset library/queue still span all projects; do not claim universal filtering.
- `branding/DramaFactory.icon`: native Icon Composer document. Compile with Apple actool into Assets.car + .icns. On macOS, pass `egui::IconData::default()` explicitly as eframe's opt-out sentinel; None installs the default eframe “e” icon. Do not set a raw bitmap runtime icon: it overrides the native system-masked bundle icon.
- `src/store.rs`: SQLite series/episode services and optimistic screenplay saves.
- `src/character_deletion.rs`: recoverable character deletion through UI/MCP, active-library filtering, expected-entry guards, saved-plan/active-job blockers and series-scoped restoration. Original library rows, profiles, prompts, styles, media and history are retained; generation rejects deleted entries.
- `src/character_profile.rs`: 43 optional character attributes, original biography as summary, readable combined production brief, atomic profile/brief saves and expected-state conflicts. UI and MCP share the service; sidekick structured proposals support guarded drafts/Undo. Approved references and independently authored portrait prompts stay unchanged. Hosted portrait generation snapshots the complete saved profile plus additional prompt direction and style; form traits take precedence, and unsaved/stale GUI forms must be saved or reloaded before queueing. Legacy plain-text brief edits require explicit reconciliation with an existing structured profile.
- `src/production.rs`: migrations, typed render/export requests, shots, cast/locations, dialogue, assets, configuration.
- `src/story.rs`, `src/story_ui.rs`: revisioned series bible, cast arcs, ordered episode outlines, setup/payoff map, declared fact checks, reviewed episode canon and downstream stale detection. Structural checks do not prove narrative or visual quality. Export snapshots include screenplay and cast/location context.
- `src/directing.rs`, `src/directing_ui.rs`: series creative profile, stable shot cast/location links, reusable camera geometry, optimistic direction/camera edits, and shared reference-guided render preparation. Fractional shot lengths round UP to 4n+1 frames. Only the first linked cast member's image conditions the current single-reference Wan adapter; other characters require editorial identity review.
- `src/sound.rs`: managed WAV imports and music/SFX timing/trims/gain/fades. Existing cue edits/removals require expected saved snapshots; GUI uses explicit drafts and exit snapshots. MCP sees saved state, not unsaved GUI drafts.
- `src/rehearsal.rs`: audio-first dialogue rehearsal request snapshots and timing validation; worker emits a WAV without requiring video takes. This is never a final episode cut.
- `src/orchestration.rs`: atomic resumable episode speech production. Verify selected take hashes, reuse pending jobs across concurrent producers, retry current failed/canceled attempts and queue only missing speech. This does not author scripts or approve performances.
- `src/library_editing.rs`: UI/MCP cast/location name and brief edits with expected-text conflicts, idempotent retries and exit-draft snapshots. Stable IDs, selected references and current voices remain intact; changed briefs invalidate matching final-cut canon.
- `src/readiness.rs`: read-only UI/MCP episode production checklist, missing media/review/reference planning issues and actual export-request gates. Explicit snapshot; no hash/decode/editorial approval claim.
- `src/transitions.rs`: shared UI/MCP picture fades from/to black within existing shot durations, optimistic expected-state saves and draft snapshots. Export-only effects preserve dialogue timing and generated takes; zero defaults preserve old final-cut snapshots. Overlapping dissolves remain incomplete.
- `src/editing.rs`: non-destructive picture in-points and durations, optimistic expected-range/take checks, shared UI/MCP controls. Picture trims preserve independent dialogue timing; review lip sync afterward.
- `src/takes.rs`: video-result registration preserves newer take selections, shot/trim/reference edits and late cancellation. Legacy requests without a selection snapshot retain results without automatic selection.
- `src/performance_window.rs`: same-episode/same-primary-character speech windows, source sample offsets and bounded take timing. Full speech assets stay in the episode mix; new takes bind source line IDs and reject stale offsets. Technical/sample/export and real generation verified; Leah windowed takes rejected for visual/speech quality.
- `src/performance.rs`, `workers/performance.py`: experimental offline LTX 2.3 image/audio acting, one generated voice line per shot. Immutable request settings, per-attempt copied/hashed inputs, bounded frames/memory/runtime, cancellation and manual review. Speech/timing changes invalidate performance selection/export. Never treat technical success as lip-sync approval.
- `src/mcp.rs`: maintained `rmcp` SDK, stdio transport, shared application services. No stdout diagnostics.
- `src/dialogue_timing.rs`: read-only UI/MCP registered speech timing, unknown implicit starts, overlaps, J/L-cut and episode bounds, and dialogue-free gaps. Gaps do not prove silence or acting quality; hash/listening/word-alignment checks remain separate.
- `src/dialogue_editing.rs`: shared UI/MCP same-episode dialogue moves with expected source/revision guards. Preserve ID, selected/pending speech, voice revision, visibility and absolute timing; known implicit starts become explicit, unknown starts reject. Native acting supports one visible line alongside off-screen lines.
- `src/dialogue_direction.rs`: on/off-screen speaker direction shared by UI/MCP. Preserves speech/voice revision and timing, advances authoring revision; blocks native acting and shot-linked lip sync for off-screen lines. Export snapshots preserve the direction. No automatic visual speaker detection.
- `src/runtime.rs`, `src/runtime_ui.rs`, `workers/diagnostics.py`: explicit offline import/FFmpeg checks; bounded child runtime/output, background GUI and shared MCP service. No checkpoints loaded; import success is not compatibility, GPU or acting approval.
- `src/models.rs`: shared UI/MCP required-file diagnostics. Empty folders do not imply available models; file presence is explicitly distinct from dependency/runtime/quality verification.
- `src/inputs.rs`: Wan/image queue-time reference hashes, create-new attempt-local copies and consumed-byte provenance. Changed references fail before model startup; legacy attempts explicitly lack a queue-time verification claim. Image approvals guard intervening library brief/reference changes.
- `src/completion.rs`: atomic validated-output registration status for export/rehearsal/speech/image/native/lip-sync. Late canceled outputs remain reviewable; canceled speech never auto-selects. Retry clears active output ID while preserving earlier assets/attempts; recovery honors cancellation intent.
- `src/worker.rs`: independent queue consumer. OS lock prevents duplicate consumers. Atomic job claims; per-attempt logs/output; cancellation, retry, crash recovery. Consumers drain the queue then exit. Multiple producer processes are supported.
- `workers/wan.py`, `workers/dialogue.py`, `workers/image.py`: embedded isolated inference adapters. Dependencies are pinned in `workers/requirements.lock`.
- `src/asset_catalog.rs`, `src/asset_browser.rs`: shared literal saved-text search, media/review filters and bounded pages. Search is not visual identity recognition; rejected takes remain retained.
- `src/media.rs`, `src/preview.rs`: FFmpeg metadata probing and bounded/paced background preview, explicit decoder termination/end/error states. Quick preview uses separate video/audio clocks; use original media in the system player for synchronized/full-resolution acceptance review.
- `src/updates.rs`, `src/updater.rs`: release discovery, Ed25519 verification, bounded staging, install after app exit/render completion, executable backup and bundle metadata update.
- Platform application data directory holds SQLite, models, managed references, jobs, assets, drafts, and update staging. `DRAMAFACTORY_DATABASE` overrides the database for isolated testing.
